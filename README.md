# Team AI — визуальный просмотр первой версии

Это **только набор скриншотов** работающего локального прототипа, собранный в кликабельный тур. Здесь нет данных команды, доступа к Claude или API. Страница не является публичным развёртыванием приложения.

Экраны: обзор команды, общий чат с AI, редактирование артефакта при конфликте версий, мобильный чат и панель контекста. Полный исходный код и спецификация переданы отдельно.
